Package        : ca-certificates
Debian Bug     : 1151413

It was discovered that several eMudhra intermediate CA certificates have
been compromised. Updated ca-certificate packages are provided to remove
the "emSign ECC Root CA - G3" and "Comodo AAA Services root"
certificates.

For the stable distribution (trixie), this problem has been fixed in
version 20250419+deb13u1.

We recommend that you upgrade your ca-certificates packages.

For the detailed security status of ca-certificates please refer to its
security tracker page at:
https://security-tracker.debian.org/tracker/ca-certificates

Further information about Debian Security Advisories, how to apply
these updates to your system and frequently asked questions can be
found at: https://www.debian.org/security/
